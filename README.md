# uBEAM

uBeam was an ultrasonic wireless power startup founded in 2011 by Meredith Perry (Marina del Rey, CA), backed by a16z, Upfront Ventures, Founders Fund, Mark Cuban, and Marissa Mayer. It rebranded as SonicEnergy in December 2018 and went defunct on February 5, 2024, without shipping a commercial product.

The enrichment pipeline ran on 2026-07-21: the company published no developer APIs, SDKs, or documentation, and both ubeam.com and sonicenergy.com are now parked domains (GoDaddy lander / Afternic for-sale). No API artifacts exist to harvest.
